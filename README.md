# AI量化策略可视化平台

本项目是一个基于 Python (FastAPI) 和 React (Vite + Ant Design) 的量化交易策略回测平台。

## 项目结构

- `server/`: 后端代码
  - `core/`: 核心回测逻辑 (Backtrader 封装)
  - `main.py`: FastAPI 接口服务
- `web/`: 前端代码 (React)
  - `src/App.jsx`: 主界面逻辑

## 启动方式

### 1. 启动后端服务

打开终端，进入项目根目录：

```bash
# 安装依赖
pip install -r server/requirements.txt

# 启动服务
python server/main.py
```

服务将在 `http://localhost:8000` 启动。

### 天勤 TqSdk 免费行情

回测页和明日策略页新增“行情供应商”，可在原有来源和“天勤 TqSdk 免费版”间切换。
“合约口径”单独选择主力连续或加权指数。天勤免费版在本平台仅接入期货。

1. 在 [快期用户中心](https://account.shinnytech.com/) 注册普通快期账号；本接入只读取行情，不需要期货交易账户。
2. 安装更新后的后端依赖：`pip install -r server/requirements.txt`。
3. 复制根目录 `.env.example` 为 `.env`，在本机填写 `TQ_USERNAME` 和 `TQ_PASSWORD`。`.env` 已被 Git 忽略；不要把凭据提交到仓库或粘贴到聊天中。也可通过同名环境变量配置，环境变量优先。
4. 在界面选择“天勤 TqSdk 免费版”。配置在下次请求时读取，无需重启；状态提示会在切换供应商或刷新页面时更新。

本接入只调用免费滚动序列 `get_kline_serial`，每次最多 10000 根，**没有调用专业版历史下载接口**。
实际覆盖时间依品种、周期和账户权限而定；没有选择日期时使用可返回的近期窗口，超出窗口的日期请求会明确报错，不会更换供应商、合约口径或周期。
自动优化和明日策略详情沿用所选供应商；结果和手动保存的历史记录包含实际来源、天勤合约代码和数据起止时间。

时间统一转换为北京时间。分钟线按 K 线起点加周期判断完成；日线保守地以对应日期 15:15 为完成界限，盘中不使用当日未结束日线。
分钟线日期筛选按北京时间自然日，夜盘以图中实际时间显示。开始日期最多容许 5 个自然日的休市间隔；更大的覆盖缺口会拒绝回测。

验证命令：`python -m unittest discover -s tests -v`，前端 `cd web` 后运行 `npm run build`。
尚未配置账号时可以验证配置提示和测试；真实行情连接需要在本地填写有效凭据后验证。

### 2. 启动前端界面

打开新的终端，进入 `web` 目录：

```bash
cd web

# 安装依赖 (如果尚未安装)
npm install

# 启动开发服务器
npm run dev
```

浏览器访问显示的地址 (通常是 `http://localhost:5173`)。

## 功能特性

- **K线对比**：侧边栏最下方进入，默认天勤期货数据。选择 10～500 根同周期 K 线，可指定基准结束时间和历史搜索范围，按开高低收的标准化形态距离查找相似片段。排名结果互不重叠，历史片段及后续观察区间均早于基准；点击结果查看叠加曲线和两组 K 线。相似度为形态分数，不是上涨概率。只在实际可获取的最近最多 10000 根数据内搜索；原有来源在此功能中仅支持主力连续日线，避免分钟或指数数据被静默替换。

- **策略配置**：支持动态调整均线周期、ATR止损倍数、风险系数等。
- **后续逐根详情**：K 线对比的历史排名每行提供“详情”，展示后续每根 K 线的时间、开收盘、前收、本根收减开、较前收涨跌额/幅及累计涨跌额/幅。第一根以前述历史匹配末根收盘为前收，累计始终以该收盘为基准；沿用本次查询的后续观察根数，超过 20 根时分页。数据直接使用已返回的历史 K 线，缺失价格留空，零观察根数时显示空状态，不额外请求行情。
- **原油与白银行情栏**：近期消息页面顶部显示金十 MCP 的布伦特 `UKOIL`、WTI `USOIL` 与现货白银 `XAGUSD` 最新报价、涨跌额/幅、今开/最高/最低/成交量，以及北京时间的报价和获取时间。先读取 `quote://codes` 确认品种，再调用 `get_quote({code})`。原油单位为美元/桶，白银单位为美元/盎司。页面可见时每 4 分钟更新，可手动刷新；后端 60 秒共享缓存以节省各工具每日额度。三个品种独立处理错误，更新失败时明确显示上次价格和原时间；超过 15 分钟的源报价标注较早，便于识别休市或延迟。行情栏独立于新闻来源切换。
- **近期消息**：侧栏进入 `/recent-news`，中东、美国、原油三个板块支持自动外网优先、国内优先金十、仅金十、东方财富与 Google 新闻 RSS。默认先 Google，失败的板块回退到金十及东方财富；国内模式优先金十，未覆盖的历史由东方财富补充。按滚动 72 小时筛选并倒序展示，每板块最多 100 条、每页 10 条；时间均为北京时间。页面可见时每 5 分钟更新，手动刷新绕过五分钟缓存。各源缓存隔离，取数失败和历史未取全均有提示，逐条保留来源与原文链接。
- **金十官方 MCP**：在 Git 忽略的根目录 `.env` 中配置 `JIN10_MCP_TOKEN`，后端直接以 Bearer Token 访问 `https://mcp.jin10.com/mcp`，不向浏览器下发凭证；无 Token 时使用公开快讯。流程为 `initialize` → `notifications/initialized` → `tools/list` / `resources/list` → `tools/call`，推荐协议 `2025-11-25`，支持 JSON 与 SSE 响应、会话头及版本协商。工具机器数据只读取 `structuredContent`，业务列表只用 `cursor / data.next_cursor / data.has_more` 分页；JSON-RPC 错误和工具业务错误分开处理。8 个工具与 `quote://codes` 通过运行时发现，可由后端 `Jin10MCPClient` 调用；本次页面使用 `list_flash`。最近 72 小时数据和历史续传游标保存在 Git 忽略的 `.venv/jin10_mcp_news.json`，按增量更新；工具用量按北京时间自然日、各工具分别记录在 `.venv/jin10_mcp_usage.json`，本地 1440 次后停止，为服务端 1500 次上限预留余量，实际剩余额度仍以服务端为准。`/api/news/jin10/status` 仅返回配置及连接状态。接口未提供足够三天历史时如实提示，国内模式可使用东方财富补充。
- **均线辅助对比**：K 线对比可单选或多选 MA20、MA60、MA144；不选时沿用 K 线形态评分。选择后 K 线占评分的 50%，所选均线合计占 50%且等权，比较均线形态与价格相对位置，并在形态叠加及两组 K 线图中显示所选均线。历史预热不足的窗口不参与排名，后续观察数据不参与评分。
- **均线显示**：回测、回测记录、明日策略详情及 K 线对比均支持 MA144，可通过图例显示或隐藏。按当前 K 线周期计算，日线下为 144 日均线；新结果使用可用历史预热，旧记录从保存的 K 线补算，未满 144 根时留空。
- **多品种支持**：支持生猪、烧碱、螺纹钢等期货品种。
- **可视化回测**：展示账户权益曲线和关键绩效指标 (Sharpe, Drawdown, Win Rate)。
- **指标计算**：
  - **一手盈利百分数**：计算公式为 `每手累计净利润 / 平均开仓价格`，反映账户相对于平均开仓成本的总收益率。
  - **一手最终赚钱数**：反映扣除佣金后的每手累计净利润。
- **交易日志**：详细记录每笔交易的执行情况，包括收益率统计。
